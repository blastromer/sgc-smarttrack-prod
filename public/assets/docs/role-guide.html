How the portal works

SGC SmartTrack is the school-to-division FAT platform for SDO Cadiz City. A school encodes 12 functionality indicators. Functional status requires 10 of 12 Yes answers, each Yes backed by a valid Minimum MOV. The Validity Form is required for every packet.

One FAT packet is shared by School ID and cycle. The Encoder and School Head of the same school work on the same packet.

The school path is:

Encode → MOV files → School Head QA → Submit to Division → Validation → Result (Functional 10/12)

Order of work

  1. On a new production site, open /setup and create Super Admin. This is available only while no Super exists.
  2. Super Admin signs in and creates the Division Admin under Users & roles.
  3. The School Head registers with a unique school name and School ID, then waits for Division Accept.
  4. Teachers register as Encoder using that same school name and School ID. They cannot register until the Head is active.
  5. The School Head accepts those teachers under Encoders.
  6. The Encoder (or Head) answers Yes / No for all 12 indicators and uploads Minimum MOVs plus the Validity Form.
  7. The School Head certifies QA and submits to Division. Only the Head can submit or withdraw.
  8. Division reviews each MOV, Accepts or Returns flagged files, then completes the review.
  9. If a file is returned: replace only that file, recertify QA, resubmit. Do not rebuild the packet.

1. Super Admin

Opens the portal, creates the Division Admin, watches live counts, and can clear school FAT data for a new cycle.

Platform owner. One Super Admin is created on /setup while the system is empty. Super does not encode school packets or validate MOVs.

This role can

  • Create the first Super Admin on /setup.
  • Create Division Admin accounts under Users & roles.
  • Watch Overview, Divisions, and Cycles with live database counts.
  • Reset School Heads, Encoders, packets, and MOV files without dropping Super or Division accounts.

This role cannot

  • Register as a school or accept School Heads.
  • Encode indicators, upload MOVs, or certify QA.
  • Accept or return school files in the validation queue.

2. Division Admin

Accepts School Heads, validates MOV files, and records Functional or Not Yet Functional for SDO Cadiz City.

SDO Cadiz City SGC focal or validator. Created by Super Admin. Does not register on the public Register page.

This role can

  • Accept pending School Head registrations.
  • See schools that belong to this division.
  • Review submitted packets, download MOVs, Accept or Return a file with a reason.
  • Complete review so the school result is posted.

This role cannot

  • Create Super Admin or another Division Admin.
  • Accept Encoders. That is the School Head.
  • Encode a school packet or certify School Head QA.

3. School Head

Owns the school identity, accepts teachers, certifies QA, submits to Division, and can remove or withdraw unapproved files.

Principal, Head Teacher, Teacher-in-Charge, or Officer-in-Charge. Registers with a unique school name and School ID.

This role can

  • Register as School Head and wait for Division accept.
  • Accept Encoder (teacher) registrations for the same School ID.
  • Encode indicators and upload MOVs, or let the Encoder do that work.
  • Remove an unapproved MOV, certify School Head QA, submit, and withdraw if Division has not accepted any file yet.

This role cannot

  • Create Division Admin.
  • Accept another School Head.
  • Register a second Head with the same school name or School ID.
  • Remove a MOV that Division already marked valid.

4. Encoder

Teacher who encodes Yes / No, uploads MOVs, and requests removal of a wrong file. Cannot submit to Division.

Teacher, SGC coordinator, or other school staff on the Encoder position list. Registers only after an active School Head exists for that School ID.

This role can

  • Register as Encoder using the Head’s school name and School ID.
  • Encode Yes / No on My assessment.
  • Upload Minimum MOVs and the Validity Form.
  • Request removal of an unapproved file so the School Head can delete it.
  • Replace a MOV that Division returned.

This role cannot

  • Register before the School Head is active for that School ID.
  • Use a different school name from the Head.
  • Certify School Head QA, submit, or withdraw the packet.
  • Remove a file directly. Request removal instead.

  • One School ID = one packet. Do not invent a second school code for the same school.

Returned or invalid MOV

Division returns only the flagged file. The school does not rebuild the packet.

  1. The Encoder replaces that file on MOV files.
  2. The School Head certifies School Head QA again.
  3. The School Head clicks Resubmit to Division.

Registration rules and positions

School Heads register first. School name and School ID must be unique among Heads. Encoders must type the Head’s exact school name and School ID. Position is a select list that depends on “I am registering as.”

School Head positions

School Head, Principal I–IV, Head Teacher I–VI, Teacher-in-Charge, Officer-in-Charge.

Encoder positions

Teacher I–III, Master Teacher I–III, SGC Coordinator, SGC Secretary, SGC Teacher-Member, SPED Teacher, Guidance Counselor, Administrative Officer.

Division Admin positions

Created by Super Admin, not by Register: Schools Division Superintendent, Assistant Schools Division Superintendent, SGOD Chief, CID Chief, Education Program Supervisor, SGC Focal Person, Public Schools District Supervisor, Division Validator.
